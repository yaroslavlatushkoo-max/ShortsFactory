# ShortsFactory Pro — готовый продукт

**ShortsFactory Pro** — локальная студия коротких блочных мультфильмов в стиле
Minecraft (Стив и Алекс). Одна идея превращается в готовый вертикальный ролик
1080×1920 с озвучкой, мимикой и липсинком, монтированный и проверенный
автоматическим контролем качества. Всё работает локально: без облаков,
подписок и внешних сервисов.

---

## Что делает продукт

- **Идея → фильм одной командой.** Локальная LLM (Ollama, `qwen2.5:7b`)
  пишет раскадровку; контрактный слой чинит и валидирует её (неизвестное
  отбрасывается с человекочитаемым журналом), а автопостановка (эмоции,
  реакции слушателя, передача предметов, открытие дверей) ставит сцену сама.
- **Скиновый липсинк.** Рты персонажей — три скина (closed/round/open),
  переключаются покадрово точно по измеренной речи (сегменты из WAV TTS);
  после каждого рендера считается lip-sync QC-отчёт (verdict pass/warn).
- **QC-гейт перед рендером.** Пересечения персонажей, недосягаемые предметы,
  обрезанные кадры — рендер не начинается (пороги: 0.05/0.4/0.35 м,
  bypass `SHORTSFACTORY_QC_GATE=0`).
- **Камера-режиссёр.** `plan_framing` строит планы по bbox «актёры + предметы»
  (поле 0.4 м): сундук и куб не обрезаются; близкие планы кадрируют пару.
- **Свет.** Клампы POINT ≤ 15 Вт и emission ≤ 2.5 — светящиеся предметы не
  пересвечиваются (blown-пиксели ≤ 0.5%).
- **Живой слушатель.** Пока один герой говорит, второй кивает/реагирует
  (жест по эмоции реплики, поворот к говорящему) — реакции выпекаются в кадры.
- **Музыка.** Процедурная подложка (−28 dBFS, fade 1.5 с), флаг `audio.music`
  в `config/config.toml` (по умолчанию выключена).
- **Сериалы.** `--episodes N` делит раскадровку на серии: `ep_01..ep_N` +
  `series_report.json` со сводным статусом.
- **Статусные отчёты.** У каждого фильма: `film_report.json` (статусы сцен,
  длительности, QC), `contact_sheet.jpg` (плитка кадров), субтитры `.srt`,
  `qc_report.json` у payload'а, лип-отчёт в diagnostics.

## Быстрый старт

### Вариант 1 — десктоп-приложение (exe)

```powershell
# 1. Сборка (один раз)
powershell -ExecutionPolicy Bypass -File build_exe.ps1
# 2. Запуск
dist\ShortsFactoryDesktop\ShortsFactoryDesktop.exe
```

В приложении: **Фильм** (идея → ролик), **Сериалы** (идея → N серий),
**Библиотека** (готовые ролики с превью), **Настройки** (музыка, окружение),
**Диагностика** (проверка Blender/FFmpeg/Ollama). Тёмная тема, шрифт
Montserrat, индикаторы окружения в шапке.

### Вариант 2 — CLI

```powershell
# активировать venv
.venv\Scripts\Activate.ps1

# фильм из идеи (одной командой)
python -m shortsfactory blocky-create --idea "Стив и Алекс находят говорящую дверь" --json

# сериал из 3 серий
python -m shortsfactory blocky-create --idea "Приключения с алмазом" --episodes 3

# из готовой раскадровки
python -m shortsfactory blocky-create --storyboard path\to\storyboard.json
```

## Требования

- Windows 10/11, Python 3.11+ (для CLI), FFmpeg в PATH, Blender 5.x
  (`D:\Blender\blender.exe` или в PATH / `BLENDER_EXECUTABLE`), Ollama с
  `qwen2.5:7b` (без неё — детерминированный fallback-сюжет).
- Piper-голоса уже в `models/piper/` (ru: dmitri/irina, en: libritts_r).

## Артефакты фильма

| Файл | Что это |
|---|---|
| `film.mp4` / `final_audio.mp4` | готовый ролик (видео+звук) |
| `film_report.json` | статусы сцен, длительности, QC |
| `contact_sheet.jpg` | плитка кадров всего фильма |
| `subtitles/<lang>.srt` | субтитры |
| `scene_XX/render/qc_report.json` | пре-рендер QC-гейт |
| `scene_XX/render/*_diagnostics.json` | лип-синк и рендер-метрики |

## Ключевые команды CLI

`blocky-create` (идея/раскадровка → фильм/сериал), `bfilm` (сцена JSON),
`bqc` (QC сцены), `breg` (золотой регресс), `animate` (2D-движок),
`doctor` (проверка окружения), `status/inspect/report` (задания).
