# Бесплатный локальный конвейер анимации — результаты

Дата: 2026-10-27.

## Что сделано

Построен полностью локальный, бесплатный режим `free_create` в ShortsFactory
(миссия 5). Никаких платных API и облачных вызовов не производилось. Ключи
не читались и не выводились.

### Компоненты (создано/изменено)

1. `src/shortsfactory/animation/environments.py` — добавлено окружение
   **`forest`** (сумеречный лес): фоновый слой (закатный градиент, луна,
   светящийся горизонт, силуэты деревьев), средний (земля, стволы, кусты,
   мягкое свечение у якоря камня), передний (тёмная листва, виньетка,
   детерминированные светлячки).
2. `src/shortsfactory/generative/animation_plan.py` **новый** — единый
   крос-движковый план (`AnimationPlan` и связанные dataclass) с валидацией
   и компиляцией в сцену v2 процедурного движка.
3. `src/shortsfactory/generative/blender_adapter.py` **новый** — адаптер
   Blender/EEVEE: генерация самодостаточного `.py`-скрипта (сцена, светящийся
   камень, иерархический humanoid, библиотека действий walk/crouch/pickup/react,
   камера, рендер PNG-последовательности, кодирование FFmpeg).
4. `src/shortsfactory/generative/engine_dispatcher.py` **новый** — выбор
   движка: `blender` (если доступен), иначе `procedural`; правила fallback.
5. `src/shortsfactory/generative/freeanim.py` **новый** — сборка пайплайна
   `free_local`: идея→Ollama→план→рендер→Piper→субтитры→QC→MP4.
6. `src/shortsfactory/generative/__init__.py` — экспорт новых API.
7. `src/shortsfactory/cli.py` — подкоманда **`free-create`**.

### Тесты

- Новый файл `tests/test_free_create.py` (12 тестов): валидация/детерминизм
  плана, компиляция в сцену, рендер процедурного движка, fallback при
  отсутствии Blender, генерация (но не запуск) Blender-скрипта, end-to-end
  малый рендер, запрет на перезапись без `--overwrite`, `--resume`,
  и **блокировка создания облачного backend** в `free_local`.
- Полный набор тестов: **все зелёные** (регрессия сохранена, включая прежние
  миссии и все 8 провайдеров).

## Демонстрационный ролик (реальный MP4)

Команда:

```powershell
cd D:\ShortsFactory
$env:PYTHONPATH='src'
python -m shortsfactory.cli free-create --script "Майя находит светящийся камень в сумеречном лесу, наклоняется, поднимает его и реагирует на свечение" --title "Майя и светящийся камень" --output "output\free_demo" --duration 15 --engine auto
```

Файл: **`D:\ShortsFactory\output\free_demo\render\procedural\pilot.mp4`**
(существует, ~2,79 МБ, декодируется).

### Проверенные характеристики (ffprobe)

- Видео: H.264, 1080×1920, 30 fps.
- Аудио: AAC.
- Длительность: 15.0 с (ролик 10–20 с — соответствует ТЗ).

### QC-статус: `READY` (все ключевые проверки прошли)

| Проверка | Значение |
|---|---|
| decode_ok | true |
| streams_ok | true |
| unique_frame_fraction | 1.0 (кадры меняются) |
| motion_ok / character_walks | true / true |
| props_interacted / attachment_verified | true / true (камень следует за рукой) |
| audio_present / audio_video_match | true / true |
| subtitles_present / subtitles_parsed | true / true |
| duration_s / width / height / fps | 15.0 / 1080 / 1920 / 30.0 |
| render_errors | 0 |

### Сюжет ролика

Майя (риг humanoid_v1, фиксированная палитра) идёт по сумеречному лесу,
наклоняется, поднимает светящийся камень (объект `gem`; событие привязки
к руке `hand_r`), реагирует на свечение. Присутствует осмысленный переход
камеры: широкий план → крупный (zoom 1.0 → 1.35). Три русские реплики
озвучены Piper, субтитры — SRT + ASS.

## Время

Рендер полного ролика (450 кадров, 1080×1920@30): **~137 с** (2,3 мин).

## Ограничения и честные заметки

- **Blender не установлен** на машине: адаптер реализован, но его рендеринг
  **НЕ проверен**. Поэтому демонстрация выполнена процедурным 2D-движком.
  Проверить рендер Blender можно после установки Blender
  (переменная `BLENDER_EXECUTABLE` или наличие в PATH).
- Движок — 2D-марионетка (фронтальный вид, FK), нет настоящего 3D,
  физически корректной походки и сложной мимики.
- Озвучка Piper — синтез речи; синхронизация губ — по огибающей, не по
  фонемам.
- Сценарий для демонстрации сгенерирован локальной Ollama (qwen2.5:7b);
  план сцен детерминированный.
- Локальная диффузионная генерация видео на данной машине (4 ГБ VRAM)
  нецелесообразна — это зафиксировано в исследовании.
