# Бесплатный локальный конвейер анимации — исследование

Дата: 2026-10-27. Цель миссии 5 — построить полностью бесплатный локальный
пайплайн: текстовая идея → короткий вертикальный MP4 (1080×1920, 30 fps)
с реальной анимацией, локальной озвучкой и субтитрами, без платных API,
облачных вызовов и ручной сборки.

## Оборудование (измерено ранее)

- Windows, NVIDIA RTX 3050 Ti Laptop, **4 ГБ VRAM** (локальная генерация
  видео с диффузионными моделями практически невыполнима).
- RAM ≈ 16,8 ГБ; Python 3.12; FFmpeg установлен; Piper TTS установлен.
- Ollama работает локально на http://localhost:11434 (модели: qwen2.5:7b,
  qwen3:4b, deepseek-v4.1-flash, gemma3, minicpm-v, llava).

## Выбранный стек

**Процедурный 2D-движок ShortsFactory** (уже существует, переиспользован
без переписывания) как реальный «движок анимации» + **Ollama** для сценария
+ **Piper** для озвучки + **FFmpeg** для сборки. Blender-адаптер добавлен
как опциональный второй движок, но не проверен, так как Blender не установлен.

Почему процедурный 2D: он уже даёт *настоящее движение* (марионеточный
скелет, FK-руки/ноги, позы, ходьба, взаимодействие с предметами с проверкой
траекторий), полностью офлайн, бесплатен и детерминирован. Камерное
«слайд-шоу» — не анимация; здесь движение генерируется физически.
