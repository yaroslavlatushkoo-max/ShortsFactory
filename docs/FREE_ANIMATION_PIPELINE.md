# Бесплатный локальный конвейер анимации — архитектура и запуск

Режим `free_local`. Полностью локальный, бесплатный, без облачных вызовов
и без платных API. Цепочка:

`Ollama → сценарий → план сцен → анимация (процедурный 2D или Blender) → Piper TTS → субтитры → QC → MP4`

## Профиль `free_local` (гарантии)

- Облачные видеопровайдеры (Kling/Veo/Fal) **отключены** — в этом режиме
  никогда не создаётся облачный backend (`create_backend` не вызывается).
- Сетевые генерации запрещены. Fallback на платный сервис исключён технически.
- Пользовательские сценарии никуда не отправляются (кроме локальной Ollama).
- Стоимость облачных вызовов всегда равна нулю, потому что такие вызовы
  исключены из режима.
- Ключи/`.env` не читаются, не выводятся и не меняются.

## Команда CLI

```powershell
cd D:\ShortsFactory
$env:PYTHONPATH='src'
python -m shortsfactory.cli free-create --script "Идея ролика" --title "Название" --output "output\free_demo"
```

### Флаги

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `--script` | — (обязателен) | текст идеи или путь к файлу |
| `--title` | — | заголовок |
| `--output` | — | папка результата |
| `--engine` | `auto` | `auto`/`procedural`/`blender` |
| `--ollama-model` | модель из конфига (qwen2.5:7b) | модель Ollama для сценария |
| `--piper-voice` | голос по умолчанию | голос Piper |
| `--duration` | `15.0` | длительность (6–30 с) |
| `--quality` | `high` | `low`/`medium`/`high` |
| `--resume` | нет | возобновить с готового рендера |
| `--overwrite` | нет | перезаписать непустую папку |
| `--json` | нет | вывод отчёта в JSON |

### Движки

- `--engine procedural` — существующий процедурный 2D-движок (работает сейчас).
- `--engine blender` — Blender+EEVEE (адаптер реализован; если Blender не
  установлен — статус `PARTIAL` с пояснением, fallback не включается).
- `--engine auto` — использовать Blender, если он доступен, иначе процедурный.

## Этапы пайплайна

- **A. Идея → сценарий.** Локальная Ollama расширяет идею в связный рассказ.
  Детерминированный fallback — исходная идея, если Ollama недоступна.
- **B. План сцен.** Детерминированный план (`AnimationPlan`): персонаж,
  объект (светящийся камень), действия (ходьба/наклон/подъём/реакция),
  событие привязки камня к руке, камера (широкий→крупный план), реплики.
  Валидация: положительные длительности, известные действия, рефы персонажей,
  наличие камеры и реплик. Сохраняется в `animation_plan.json`.
- **C. Персонажи и согласованность.** Стабильный персонаж «Майя» (риг
  humanoid_v1, фиксированная палитра), единое окружение `forest` (палитра,
  свет, якоря). Консистентность обеспечивается повторным использованием
  одних и тех же ассетов/рига.
- **D. Анимация.** Движок генерирует **реальное движение**: ходьба
  (перемещение корня), наклон (поза), подъём камня с привязкой к руке
  (`attach` на `hand_r`), реакция-сюрприз, радость. Проверки: движение
  конечностей без движения камеры, привязка камня к руке (≤ заданного
  порога), изменение кадров, отсутствие пустых кадров.
- **E. Озвучка.** Piper TTS, русские реплики, привязка к таймлайну
  (старт реплики) и синхронизация губ по огибающей.
- **F. Субтитры.** Генерируются `subtitles/ru.srt` и `subtitles/ru.ass`.
- **G. Монтаж и экспорт.** FFmpeg: вертикальное видео 1080×1920, 30 fps,
  H.264 + AAC. Проверка длительности/разрешения/fps/декодируемости.

## Контроль качества

Статусы: `READY`, `PARTIAL`, `WARNING`, `FAILED`. `READY` ставится только
если все ключевые проверки прошли (декодирование, движения, привязка предмета,
аудио, субтитры).

Метрики в `qc`:
- `duration_s`, `width`, `height`, `fps`, `streams_ok`, `decode_ok`;
- `unique_frame_fraction` — доля уникальных кадров (выборка кадров с
  замороженной камерой, хэши SHA-256);
- `motion_ok`, `character_walks` — из проверок движка;
- `props_interacted`, `attachment_verified` — проверка взаимодействия с предметом;
- `audio_present`, `audio_video_match` — длительность аудио против видео;
- `subtitles_present`, `subtitles_parsed` — наличие и корректность SRT.

## Артефакты результата

- `render/procedural/pilot.mp4` — итоговое видео;
- `render/procedural/contact_sheet.jpg` — контактный лист;
- `render/free_scene_01.json` — сцена движка;
- `render/procedural/characters.json`, `report.json`, `report.md`;
- `animation_plan.json` — план сцен;
- `subtitles/ru.srt`, `subtitles/ru.ass`;
- `free_report.json` / `free_report.md` — итоговый отчёт.

## Надёжность / возобновление

- `--resume` переиспользует готовый рендер (`render/procedural/pilot.mp4`),
  если он есть, не пересчитывая его.
- Повторный запуск в непустую папку запрещён без `--overwrite`.
- Режим `free_local` не создаёт облачный backend — это защищено тестом.
