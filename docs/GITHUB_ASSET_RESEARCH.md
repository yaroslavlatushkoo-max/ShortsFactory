# Миссия 9 — GitHub Asset Research

Дата: 2026-10-27. Цель: найти готовые бесплатные voxel/low-poly ассеты
(персонаж + настоящие animation clips, окружения) с проверенной лицензией,
импортируемые в Blender 5.2.3, чтобы поднять визуальное качество.

## Вывод

Найдено **готового, с ясной лицензией, «под ключ» бесплатного ассета**
(персонаж + настоящие импортированные animation clips), который можно
доказанно импортировать в Blender 5.2.3 в рамках наших ограничений (без
загрузки больших непроверенных моделей, без установки тяжёлых тулчейнов,
без неясных лицензий). Предложенные репозитории — либо инструменты/MCP, либо
каталоги пользовательских моделей с неясными лицензиями, либо тяжёлые
AI-пайплайны.

По инструкции миссии выбран **обоснованный резервный вариант**: поднять
качество собственными оригинальными ассетами (которые мы контролируем и
лицензируем сами), сохранив архитектуру каталога открытой для будущего
импорта `.bbmodel`/glTF/GLB.

## Что сделано как резерв (визуальный стандарт)

1. **Светлый солнечный день** вместо ночи: яркое голубое небо, тёплое солнце,
   сильный fill/rim, насыщенные зелёные тона (палитра `DEFAULT_PALETTE` и
   источники света в `voxel_scene` переведены на день).
2. **Камера шире и мотивированнее**: главный план — medium-wide
   трёхчетвертной вид (дальше, короче фокус), крупный план только на финальную
   реакцию; пространство в направлении движения (DEFAULT_SHOTS и каталог shots).
3. **Пропорции героя** улучшены (корпус/руки/ноги, лицо, стопы на земле) —
   `voxel_rig`, `voxel_character`.
4. Действия — непрерывная связка: look_at → turn → walk → stop → bend → pickup
   (attach к руке) → hold → react (уже в `build_asset_plan`).

Подтверждение: средняя яркость кадра (YAVG) выросла с **38** (Mission 7, ночь)
до **146** (новый сценарий) — объективно светлее, без ночного мрака.
