# Asset-Based Voxel Cartoon Pipeline — результаты

Дата: 2026-10-27.

## Что сделано
Построен рабочий прототип **гибридного ассет-пайплайна**: подготовленные
оригинальные персонажи, проверенные клипы, планы камеры и среда выбираются через
каталог ассетов, а Blender+ShortsFactory рендерят эпизод. Это изменение
*подхода*, а не очередная подгонка параметров.

## Файлы (создано/изменено)
- `assets/voxel/catalog.json` — каталог ассетов (персонаж, среда, пропсы,
  клипы, планы) с метаданными (источник, формат, риг, лицензия, статус).
- `assets/voxel/animations/*.json` (10) — метаданные клипов:
  idle/walk/turn/stop/bend/reach/pickup/hold/react/look_at.
- `src/shortsfactory/generative/voxel_engine/assets_catalog.py` — загрузка и
  валидация каталога (`AssetCatalog`).
- `src/shortsfactory/generative/voxel_engine/asset_pipeline.py` — план эпизода
  по id ассетов (`build_asset_plan`), валидация (`validate/ensure_asset_plan`),
  рендер (`render_asset`) с планами камеры из каталога.
- `src/shortsfactory/generative/animation_plan.py` — поле `production`
  (необязательное, обратно совместимо); `--engine asset`.
- `src/shortsfactory/generative/engine_dispatcher.py` — маршрутизация `asset`.
- `src/shortsfactory/generative/voxel_engine/voxel_renderer.py` — `build_voxel_script`
  принимает `shots` из каталога.
- `tests/test_voxel_engine.py` — +6 тестов (каталог, валидация, план, маршрут).
- `docs/ASSET_BASED_VOXEL_PIPELINE.md` (этот отчёт).

## Использованные инструменты
Blender `D:\Blender\blender.exe` (5.2.3 LTS), FFmpeg, Python, Ollama (в
`free-create`), Piper (по необходимости). Никаких платных API, облачной
генерации, ключей из `.env`. Blockbench не установлен — выбран собственный
генерируемый формат с совместимым «слотом» для будущего импорта.

## Выбранный формат ассетов
Собственный `bpy`-формат (кубическая геометрия) + каталог с метаданными.
Причина: нет Blockbench, внешние экспортёры не проверены, лицензионных внешних
ассетов нет. Интерфейс каталога позволяет позже подключить импорт glTF/GLB без
изменения остального пайплайна.

## Демо-эпизод «Герой находит загадочный куб» (9 с)
- Герой: `hero_v1` (оригинальный, повторно используемый).
- Анимации (клипы): idle → look_at → turn → walk → stop → bend → pickup →
  react → hold.
- Взаимодействие: куб привязывается к руке (событие `attach`, `hand_r`,
  6.9 с).
- Камера: `three_quarter` → `closeup` (из каталога).

**Финальный MP4:** `output\_asset_based_voxel_v1\render_final\final.mp4`
— **1080×1920, 30 FPS, H.264, 9.0 с**, декодируется.
- Blender-сцена: `render_final\render_voxel_asset_cube_01.py`.
- Контактные листы: `render_final\contact_sheet_final.jpg`, превью в
  `render_preview\`.

## Тесты
- `tests/test_voxel_engine.py` — 19 тестов (все прошли), включая новые ассет-
  тесты (загрузка каталога, валидация ссылок, отклонение неизвестного клипа,
  маршрутизация `asset`).
- Полный pytest — **зелёный**, без регрессий (старые движки и `free-create`
  работают).

- Превью 540×960: ~113 с.
- Финальный 1080×1920 (270 кадров): ~249 с.

## Ограничения и честные заметки
- **Визуальная оценка не автоматизирована**: я не могу просматривать
  изображения, поэтому композиция/выразительность оценивались по коду и
  параметрам постановки; окончательный вердикт — за человеком (контактные
  листы приложены).
- Формат ассетов — собственный `bpy`; импорт glTF/GLB не реализован
  (не проверен), но архитектура каталога допускает его добавление.
- Клипы — метаданные+генерируемые ключевые кадры (не внешние .fbx/.glb);
  «проверенность» — на уровне каталога и валидации, не художественной оценки.
- Точный IK-контакт кисти не реализован — используется контролируемая точка
  захвата с привязкой к руке.
- Нет автоматической проверки «стопы не скользят/не проходит сквозь объекты».
- `run`/`jump` не включены в эталон (по задаче — не в ущерб качеству).

- ✅ повторно используемый оригинальный персонаж (`hero_v1`);

- ✅ сохранены исходники и контактные листы;
