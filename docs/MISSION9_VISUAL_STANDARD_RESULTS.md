# Миссия 9 — Визуальный стандарт: результаты

Дата: 2026-10-27.

## Что сделано
После исследования GitHub (см. `docs/GITHUB_ASSET_RESEARCH.md`) подтверждено
отсутствие подходящего готового бесплатного ассета с ясной лицензией, поэтому
реализован резервный путь — **качественный визуальный стандарт на собственных
оригинальных ассетах**:

- **День вместо ночи**: яркое голубое небо, тёплое солнце + сильные fill/rim,
  насыщенные зелёные тона.
- **Камера**: medium-wide общий план (герой целиком + окружение, пространство в
  направлении движения), крупный план только на реакцию.
- **Герой**: улучшены пропорции, лицо, стопы на земле.
- **Действия**: непрерывная связка (заметил → повернулся → подошёл → встал →
  наклонился → взял куб (attach к руке) → рассматривает → реагирует).

## Ограничения и оставшиеся визуальные недостатки
- **Визуальная оценка не автоматизирована**: модель не просматривает
  изображения; подтверждены только технические параметры и объективная яркость
  (YAVG). Окончательный художественный вердикт — за человеком (контактный
  лист приложен).
- Импорт внешних glTF/GLB/.bbmodel ассетов не реализован (не проверен); слот в
  каталоге под будущий импорт сохранён.
- Клипы — метаданные + генерируемые ключевые кадры (не внешние .fbx/.glb);
  «настоящие импортированные animation clips» отсутствуют.
- Точный IK-контакт кисти не реализован — используется контролируемая точка
  захвата с привязкой к руке.
- Авто-проверка «стопы не скользят/не проходит сквозь объекты» отсутствует.
