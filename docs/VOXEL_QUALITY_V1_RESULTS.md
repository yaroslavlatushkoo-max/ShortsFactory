# Voxel Quality Reset — Mission 7 — результаты

Дата: 2026-10-27.

## Что сделано
Качественный сброс Voxel-движка для одной короткой сцены. Исправлены
**первопричины** плохого результата Mission 6:
1. **Камера** переработана полностью (следование за героем, постановочные
   планы, 9:16, вертикальный сенсор, фокусные расстояния, безопасное
   кадрирование) — `voxel_camera.py`.
2. **Риг/пропорции** исправлены (ноги больше не тонут, цельный силуэт,
   крупное лицо) — `voxel_rig.py`, `voxel_character.py`.
3. **Анимация** привязана к высоте бедра, добавлены действия `bend/hold/fall/
   recover`, снижены амплитуды, плавнее тайминг — `voxel_animation.py`.
4. Декор (деревья/камни) сдвинут в фон и по краям, не перекрывает героя —
   `voxel_scene.py`.
5. План новой сцены «Герой находит загадочный куб» — `voxel_engine/quality_plan.py`
   (+ поле `extra_actions` в `AnimationPlan` для валидации новых действий).

## Честные ограничения
- **Визуальная оценка не автоматизирована**: модель не поддерживает просмотр
  изображений, поэтому композиция/выразительность оценивались по коду и
  параметрам постановки; окончательный вердикт — за человеком (см.
  контактные листы). Это заявлено прямо, а не скрыто.
- Точный IK-контакт кисти с предметом не реализован — используется
  контролируемая точка захвата (куб прикрепляется к руке).
- Нет автоматической проверки «стопы не скользят»/«не проходит сквозь объекты»
  для 3D — только косвенная через привязку.
- Один план/одна сцена; серийность и новые функции — за пределами Mission 7.

## Итого
Первопричины исправлены (камера, риг, сцена, анимация), получен

Визуальная оценка оставлена человеку (контактные листы приложены).
