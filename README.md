# ShortsFactory Pro

Локальная фабрика вертикальных YouTube Shorts на русском и английском языках.
Одна команда запускает исследование, сценарий, озвучку, подбор медиа, монтаж,
субтитры, обложки, метаданные и автоматический контроль качества.

Система **не публикует видео на YouTube**. Она готовит файлы и отчёт для ручной
проверки и загрузки.

## Что уже работает

- Естественно-языковые команды на русском.
- Профили тем: наука, технологии, история, природа, география, объяснения,
  биографии, культура, игры.
- Исследование по Wikipedia, NASA Images, Wikimedia Commons и Openverse.
- Строгая проверка лицензий медиа: PD, CC0, CC BY; CC BY-SA/NC/ND отклоняются.
- Сценарии на RU и EN с разными таймингами и отдельными субтитрами.
- Офлайн-озвучка Piper: `ru_RU-dmitri-medium` и `en_US-libritts_r-medium`.
- Сборка 1080×1920, H.264/AAC, 30 fps, динамические субтитры Montserrat.
- Animation Engine v4: 2D cut-out персонажи из декларативных SVG-ассетов,
  параллакс-фон из переиспользуемых слоёв, привязка предметов к кисти,
  библиотека поз, выражения лица и липсинк; покадровый QC кадрирования и поз;
  пилот 20 с с двумя передачами предмета между персонажами.
- Обложки 1280×720, названия, описания, хештеги и `upload_*.txt`.
- Технический, содержательный и визуальный QC с контактным листом.
- Контрольные точки, SQLite-состояние и продолжение после перезапуска.
- Повторный рендер `remake` с переиспользованием сценариев, медиа и озвучки.
- Отчёты с источниками, лицензиями медиа и версиями инструментов.

## ShortsFactory Pro — блоковые мультфильмы (готовый продукт)

Ядро продукта — конвейер «идея → блочный мультфильм с липсинком»: локальная
LLM пишет раскадровку, автопостановка ставит эмоции/реакции/передачи
предметов, скиновый рот озвучивается точно по речи, QC-гейт не пускает в
рендер пересечения и обрезки, готовый фильм собирается с субтитрами и
отчётами. Десктоп-приложение (exe, тёмная тема, библиотека готовых роликов),
сериалы (`--episodes N`), процедурная музыка (флаг `audio.music`).

- Полное описание и быстрый старт: **[PRODUCT.md](PRODUCT.md)**
- Десктоп-приложение: сборка `powershell -File build_exe.ps1` →
  `dist\ShortsFactoryDesktop\ShortsFactoryDesktop.exe`
- CLI: `python -m shortsfactory blocky-create --idea "..." [--episodes N]`

## Быстрый старт

```powershell
cd D:\ShortsFactory

# Проверить окружение
.\run.ps1 doctor

# Создать один ролик
.\run.ps1 create --topic "Космос" --duration 40 --languages ru en

# Несколько роликов по широкой теме
.\run.ps1 batch --topic "Технологии" --count 3

# Свободная команда
.\run.ps1 ask "Создай 2 Shorts о космосе, 40 секунд, RU и EN"

# Состояние и продолжение
.\run.ps1 status
.\run.ps1 resume
.\run.ps1 inspect --latest
.\run.ps1 report --latest
.\run.ps1 preview --latest

# Повторный рендер с новым темпом
.\run.ps1 remake --latest --pace fast

# Анимационный пилот v4 из сториборда (2D cut-out, отдельный режим)
.\run.ps1 animate --storyboard animation/storyboards/pilot_room_v4.json --out output/_animation_engine_v4

# Или готовая сцена напрямую
.\run.ps1 animate --scene animation/scenes/pilot_room.json

# Анимированный проект через общий конвейер (сейчас только RU и готовый сториборд)
.\run.ps1 create --topic "Пружина из шара" --visual-mode animated `
  --storyboard animation/storyboards/pilot_room_v4.json
```

Двойной клик по `ShortsFactory.cmd` открывает запрос свободной команды.
Все команды также доступны как `python -m shortsfactory ...` внутри `.venv`.


Рабочие файлы, промежуточная озвучка, исходные кадры и история этапов лежат в
`workspace/<project_id>/`. Они не удаляются автоматически.

Анимационный режим пишет отдельный набор, не затрагивая проекты изображений:

```
output/_animation_engine_v4/
  pilot.mp4               # 1080×1920, 30 fps, H.264/AAC, 20 с
  contact_sheet.jpg       # 9 кадров: две передачи, отпускание, реакции
  frames/frame_01.jpg … frame_09.jpg
  report.md, report.json  # метрики, кадрирование, контроль поз, привязка, липсинк
  scene.compiled.json     # сцена, которую можно править вручную
  storyboard.source.json  # исходный сториборд
  pilot_scene.json, characters.json
  audio/voice.wav
```

Пилоты v1 (13 с) и v2 (17 с) остаются в
`output/_animation_engine_v1/` и `output/_animation_engine_v2/`.

## Статусы

`QUEUED → PLANNING → RESEARCH → SCRIPTING → LOCALIZATION → ASSETS → VOICE →
EDITING → RENDERING → METADATA → QUALITY_CHECK → READY`

- `READY` — все обязательные проверки пройдены; художественная часть всё равно
  требует быстрой ручной проверки.
- `PARTIAL` — файлы созданы, но есть обязательные замечания или предупреждения.
- `FAILED` — этап не завершён; диагностика сохранена.
- `INTERRUPTED` — процесс был прерван; `resume` или `retry` продолжат с
  незавершённого этапа.

## Требования

- Windows 10/11, Python 3.11+ (проект проверен на 3.12.13).
- FFmpeg и ffprobe в `PATH` (проверено на 8.1.1).
- Ollama с моделью `qwen2.5:7b` — для качественных сценариев; без неё работает
  экстрактивный резервный режим.
- Около 1 ГБ свободного места для моделей и одного проекта; медиа кэшируются.
- Интернет — для исследования и загрузки медиа. Без него можно использовать
  собственный сценарий из `input/`.

## Ограничения

- Автоматическая проверка не заменяет художественную оценку: контактный лист и
  отчёт нужно просмотреть вручную. Смысловые ошибки сценария и неудачные
  визуальные ассоциации QC не ловит.
- qwen2.5:7b может требовать 2–3 попыток; при исчерпании попыток включается
  экстрактивный резервный режим, который помечается в сценарии.
- Система не гарантирует вирусность, монетизацию или абсолютную фактическую
  точность. Источники и предупреждения сохраняются в отчёте.
- Публикация на YouTube не автоматизирована.
- `en_US-ryan-high.onnx` не используется: лицензия CC BY-NC-SA не подходит для
  монетизируемого контента.
- Анимационный движок — производственный прототип, а не готовый сериал:
  персонажи остаются аккуратными векторными манекенами, фон собран из трёх
  слоёв с параллаксом, но физика предметов кинематическая (без гравитации и
  столкновений), липсинк по громкости. Привязка предмета, передача и библиотека
  поз работают. Двуручного захвата и подвижных пальцев нет. Сториборд —
  структурированный JSON с ограниченным набором команд; произвольный текст в
  анимацию не превращается, а `create --visual-mode animated` требует готовый
  сториборд и сейчас создаёт только русскую версию.
